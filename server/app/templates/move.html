How moving works

  1. On the new server: install Camera Keeper (Windows: CameraKeeper-Setup.exe). Don't sign in to Arlo there.
  2. On the old server: Download export below.
  3. On the old server: Turn off recording here (Arlo only allows one server per login).
  4. On the new server (open http://localhost:{{ port }}/move there): Import the file. Arlo accounts, phone numbers, alert settings, the away-from-home password, Barb's photo and the clips all come along.
  5. On the new server: Point bcn.tapper.co here. Phones away from home follow automatically; on the home Wi-Fi the app finds the new server by itself.
  6. Delete the export file: it holds the Arlo and Twilio passwords.
