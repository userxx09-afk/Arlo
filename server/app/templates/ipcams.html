Add a Laview or other IP camera

Cameras that send video on the home network (RTSP), like Laview's IP cameras and recorders (NVR/DVR), and most ONVIF cameras. Their motion pops up on GarysTV (tick them in Settings › Arlo), goes to the phone app and the alerts, and records a clip, the same as Arlo. Live view works too. Use the camera's own name and password (often admin and the one set when it was activated), not the Laview app login.

{{ fields({}) }}
Tips for Laview cameras
  • Give the camera a fixed address in the router (DHCP reservation) so it keeps the same one.
  • A camera that's never been set up must be activated first (Laview ONE app, or Laview's SADP / iVMS tool) to set its password.
  • In the camera's web page (type its address in a browser): turn on RTSP (Network › Advanced › Integration protocol) and, for camera motion events, ONVIF with a user. Motion detection must be turned on in the camera for its events.
  • A recorder (NVR/DVR): enter its address and how many channels to add. Each channel becomes a camera.
  • Cloud-only Laview models (Wi-Fi cameras that only work in the app, with no RTSP/ONVIF) can't be added.
